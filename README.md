# Strezless Nexus: Music Metadata

A catalog and metadata management system for independent artists, labels, and rights teams.

Strezless Nexus helps organize the core identifiers and release data that keep a catalog clean and distributor-ready: artist profiles, releases, tracks, ISRC and ISWC tracking, UPC references, writer attribution, and metadata records used across catalog management and digital distribution.

## What it helps manage

- Artist profiles and catalog ownership
- Release and track records
- ISRC, ISWC, UPC, IPI, ISNI, and related identifiers
- Writer and split metadata
- Metadata structure for professional music operations
- A clean foundation for future release, publishing, and distribution workflows

## Project focus

This project is designed for the practical side of music operations: keeping artist data structured, searchable, and ready for downstream use in distribution, publishing, catalog administration, and rights workflows.

## Stack

- TypeScript
- Vite
- Drizzle ORM
- Netlify
